# NIVO — Verified Meme Launch Network

Premium coming-soon website for NIVO, a planned meme-token launch and discovery platform focused on creator identity, transparent token information, and public stories.

This repository is a **pre-launch marketing site only**. It does not deploy tokens, connect wallets, run OAuth, or trade assets.

## Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- Framer Motion
- Lucide Icons

## Local development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Production build

```bash
npm run build
npm start
```

## Notes

- Waitlist submission is simulated in the browser.
- Social and community buttons use placeholder URLs until official channels are provided.
- NIVO is an independent project and is not affiliated with or endorsed by Robinhood or Solana.
